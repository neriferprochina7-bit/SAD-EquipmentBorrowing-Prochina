## System Description

The Equipment Borrowing and Return Monitoring System is an online
system for managing college equipment borrowing and return transactions.

## Features

- User Login
- User Logout
- Dashboard
- Equipment Management
- Add Equipment
- View Equipment
- Edit Equipment
- Delete Equipment
- Record Borrowing
- Return Equipment
- Overdue Detection
- Search Equipment
- Search Transactions
- Filter Transactions

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL
- GitHub
- GitHub Pages

## Database

The system uses two related tables:

1. equipment
2. borrow_transactions

## Deployment

The system is deployed using GitHub Pages.
